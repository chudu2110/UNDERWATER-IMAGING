INSIDE THE NETWORK

Follow the image.
Understand the change.

From a color-shifted input to a restored image: follow the signal through white balance, wavelet features and gradient-aware refinement.

01 · Color balance→02 · Multi-scale features→03 · Edge refinement→04 · Output

READ THE DIAGRAM

One image.
Four connected ideas.

The top row shows the complete path. The enlarged blocks below explain how the network handles texture and boundaries.

01White balance & adaptive weights

The input and a white-balanced version are combined using learned channel weights. This gives the network a way to adjust blue-green color casts before extracting features.

02Wavelet features · WEB

The Haar filter bank separates low- and high-frequency features into LL, LH, HL and HH bands. The WEB combines these bands to work with broad image structure and finer texture.

03Edges & residual blocks · SGFB

Sobel gradients supply edge information. Learned weights guide its fusion with spatial features inside the WGSRB. Skip connections carry features across scales and into the output.

04Learning from a reference

During paired training, the output is compared with ground truth using Charbonnier, perceptual, SSIM, edge and HVI losses. A reference is needed for training and paired evaluation, not for enhancing your own image.

Network architecture

Scroll to explore the original diagram at full resolution.

With a reference. UFO-120 and LSUI examples include a ground-truth image. Paired evaluation uses PSNR and SSIM.

Without a reference. U45, Challenging-60 and CC7 examples support visual comparison. Non-reference evaluation uses NIQE, UCIQE and URanker; these scores are not shown for this gallery.

Method and example sources

Adapted from the official repository README and research paper. Scene inputs and available reference images come from the repository demo assets. Enhanced images were generated locally with its published UIEB checkpoint.
